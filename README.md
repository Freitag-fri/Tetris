# Tetris

Класичний тетріс у 3D на Unity 6. Робив з нуля і доводив до стану готової гри: меню, матч, рівні складності, рекорд, скіни. Грати можна свайпами з телефона або з клавіатури.

**Стек:** Unity 6, C#, Unity Input System, DOTween, ProBuilder, TextMesh Pro, Git.

## Що всередині

- **Механіка написана вручну.** Падіння фігур, розгін швидкості з рівнями, перевірка колізій, очищення заповнених ліній зі зсувом стеку, поворот біля стінки з підсуванням фігури, миттєве падіння з підсвіченим місцем приземлення.
- **Кожна фігура - це сітка 4x4.** У ній позначено, які клітинки зайняті. Обертання одне спільне, окремої логіки під кожну фігуру немає, нова фігура це така сітка плюс префаб із чотирьох кубів.
- **Гра не залежить від способу вводу.** Клавіатура і тач живуть окремо, обидва працюють з полем через спільний інтерфейс. Той самий код виконується і на ПК, і на телефоні.
- **Скіни і рекорд.** Скіни поля та блоків гортаються свайпом, перемикання анімоване через DOTween. Рекорд і вибір гравця лишаються після перезапуску, ключі PlayerPrefs зібрані в одному класі.
- **UI під різні екрани.** Canvas Scaler з базовою роздільністю під портретний формат, тіні, анімація очищення ліній, підказка про свайп у меню.
